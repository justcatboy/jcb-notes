Письма приложения (коды, сброс пароля) через SMTP-релей Brevo от адреса своего домена, например `noreply@example.com`.

## 1. Домен

Brevo → **Senders, Domains & Dedicated IPs** → **Domains** → Add a domain. Brevo покажет записи для DNS:

| Запись | Тип | Для чего |
|---|---|---|
| Brevo code | TXT на корне домена | что домен твой |
| DKIM | два CNAME (`brevo1._domainkey`, `brevo2._domainkey`) или один TXT | подпись писем доменом |
| DMARC | TXT на `_dmarc` | политика для получателей; для начала `v=DMARC1; p=none; rua=mailto:<почта для отчётов>` |

Значения — только из своего кабинета. Записи добавить в DNS → **Authenticate this email domain**. Если DNS у
поддерживаемого провайдера (например, Cloudflare), Brevo может добавить записи сам.

- В Cloudflare у DKIM-записей — **DNS only** (серое облако), иначе подпись не проверяется.
- DMARC-запись у домена должна быть **одна**: если уже есть — править её, а не добавлять вторую.
- Записи не удалять, пока Brevo шлёт от домена.
- Бесплатные ящики (`gmail.com` и т. п.) как домен отправителя не подтвердить.

## 2. Отправитель

**Senders** → Add a sender: адрес на подтверждённом домене (`noreply@example.com`) и имя, которое увидит человек.

## 3. SMTP

**Settings** → **SMTP & API** → вкладка SMTP → Generate a new SMTP key.

| Переменная | Значение |
|---|---|
| `SMTP_HOST` | `smtp-relay.brevo.com` |
| `SMTP_PORT` | `587` — STARTTLS; `465` — TLS сразу; `2525` — если 587 закрыт |
| `SMTP_USER` | поле **Login** на этой странице — часто вида `<id>@smtp-brevo.com`, **не** почта аккаунта |
| `SMTP_PASS` | SMTP-ключ (не пароль аккаунта и не API-ключ) |
| `MAIL_FROM` | `Имя <noreply@example.com>` — отправитель из шага 2, **не** SMTP-логин |

Секреты — только в окружении сервера или `.env.local`.

На зарезервированные домены (`.test`, `.invalid`, `.example`, `.localhost`) приложение не должно слать никогда — даже
с настроенным SMTP: адреса из проверок и примеров не уходят в Brevo и не тратят лимит.

## Проверить

Отправить письмо на Gmail → «Показать оригинал»: SPF, DKIM и DMARC — `PASS`, письмо не в спаме.

У Brevo свой лимит писем в сутки (зависит от тарифа) — смотреть в кабинете.
