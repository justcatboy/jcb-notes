## Суть

Чужая служба (почта, вход через поставщика, капча, платежи) не обязательна для запуска: без неё приложение работает
без её функции, а проверки проходят без настоящей службы.

## Правила

- **Нет службы — нет функции**, а не ошибка: нет кнопки входа через поставщика, нет капчи. Для обязательных служб
  записано, что без них не работает.
- **Один модуль на службу**: прямых вызовов в обход нет.
- **Решение на сбой записано**: пропустить запрос или отказать.
- **Проверки проходят без настоящей службы.**
- **Не ждать службу там, где время ответа выдаёт данные**: например, по времени ответа не должно быть видно, есть ли
  такой адрес.

## Проверка

- Приложение стартует и проходит проверки, когда необязательные службы не настроены.
- Поиск по коду: вызовы клиента службы — только в её модуле.
- По каждой службе записано, что будет без неё и при её сбое.
