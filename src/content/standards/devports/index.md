## Суть

У каждого проекта свой **блок из 10 портов** (`X0`–`X9`), и всё, что проекту нужно локально, живёт внутри блока:
сайт, база, тестовые серверы. Проекты можно запускать одновременно (и их проверки тоже), и они никогда не мешают
друг другу.

В исключительных случаях проект занимает **два блока подряд** (20 портов, `X0`–`(X+1)9`), но не отдельные порты
из разных мест: граница проекта всегда кратна 10.

## Раскладка внутри блока — рекомендация

Проект раскладывает порты сам; если причин делать иначе нет, удобно так:

| Смещение | Что |
|---|---|
| +0 | сайт при разработке |
| +1 | база при разработке |
| +2 / +3 | сайт и база автопроверок |
| +4 … +9 | всё остальное: сквозные проверки, соседние сервисы для проверок, демо |

Обязательно одно: раскладка записана в документации проекта, а значения — в его `.env`-файлах.

## Реестр блоков

Какой блок за каким проектом — один список на все проекты. Новый проект берёт следующий свободный блок и
дописывает себя в список. Список — **вне репозиториев**: ни один проект не знает о других.

## Правила

- Порты — только из `.env`-файлов, не значения по умолчанию в коде.
- Проверки никогда не трогают сайт и базу разработки: у них свои порты и своя пустая база.
- В скриптах ходить на `127.0.0.1:<порт>`, а не на `localhost`.
- Перед запуском сервера разработки проверить, не занят ли порт.
- В контейнере сайт слушает свой порт (обычно 3000), а наружу его публикуют на порт из блока.

## Проверка

- Все порты проекта в его `.env`-файлах лежат внутри его блока (или двух блоков подряд) из реестра.
- В коде нет номеров портов.
