## Суть

**Каждый коммит считается публичным.** Приватность репозитория — настройка хостинга, а не защита: репозиторий
открывают, форкают, копируют в бэкапы и показывают помощникам. Поэтому история git в любой момент такова, что её
можно выложить на GitHub, GitLab или куда угодно в открытом виде.

Личное живёт отдельно: вне репозитория или в папке, которую git игнорирует на любой машине. Бэкап личного — своим
путём, отдельно от публичной истории.

## Что считается личным

| Вид | Примеры |
|---|---|
| Секреты | токены, ключи API, пароли, строки подключения, cookies, закрытые ключи и сертификаты |
| Данные о людях | почта, телефон, адрес, настоящие имена и логины — свои и чужие |
| Данные о машине | домашний путь (`C:\Users\<имя>\…`, `/home/<имя>/…`), имя компьютера, внутренние адреса, имена сетей |
| Личное содержимое | дневник, заметки, финансы, здоровье, переписка, выгрузки чатов, закладки, профили |
| Рабочее | названия и пути чужих (рабочих) проектов, данные клиентов |
| Данные из работы программы | дампы и файлы баз, логи, бэкапы, выгрузки из служб |
| Метаданные | почта автора коммита, EXIF в фотографиях, свойства документов |

## Где живёт личное

1. **Вне репозитория** — по умолчанию: менеджер паролей, окружение процесса, папка настроек пользователя.
2. **`private/` в корне репозитория** — всё личное, что удобно держать рядом с проектом: заметки, входные файлы,
   бэкапы, настоящие данные, планы. Одна папка на всё вместо россыпи имён в `.gitignore`.
3. **Файлы `*.local` и `*.local.*`** — личное поверх общего файла, рядом с ним: `.env.local`, `CLAUDE.local.md`,
   `.claude/settings.local.json`.

`private/`, `*.local` и `*.local.*` git игнорирует **глобально** (`core.excludesFile`): так защищён любой
репозиторий, даже новый и без своего `.gitignore`. В `.gitignore` проекта они продублированы — для другой машины и
для того, кто склонирует репозиторий.

## Правила

- **Автор коммитов — адрес-заглушка хостинга** (на GitHub — `<id>+<логин>@users.noreply.github.com`), задан в
  конфиге репозитория. Глобально — `user.useConfigOnly=true`: без настройки в репозитории git просит её, а не
  подставляет имя машины.
- **Код и данные — раздельно.** Программа, которая работает с личными данными (дневник, закладки, финансы), хранит
  в git код, схему и пример данных (`data.example/` или фикстуры), а настоящие данные — в `private/` или вне
  репозитория; путь к ним — настройка окружения.
- **Примеры — заглушками**: почта `user@example.com`, домены `example.com` и `*.test`, адреса `192.0.2.x`,
  `198.51.100.x`, `203.0.113.x`, люди — вымышленные (`ivan.petrov`, `anna`), пути — относительные или через `~` /
  `$HOME`.
- **Файлы помощников** (`CLAUDE.md`, `AGENTS.md` и подобные) — только общее для всех, кто открывает проект: пути
  относительные, без личного и рабочего. Личное — в `CLAUDE.local.md` или в настройках пользователя.
- **Фотографии и документы — без метаданных**: EXIF и свойства очищены перед коммитом.
- **Бэкап личного — отдельно от публичного репозитория**: архивом, отдельным приватным репозиторием или программой
  бэкапа. Шифрованные файлы в общей истории (git-crypt, SOPS) — вне этого стандарта: история вечная, и утёкший
  однажды ключ открывает её целиком.
- **Две проверки перед каждым коммитом** (хук), обе — по тому, что уходит в коммит:
  - **сканер секретов**;
  - **личный стоп-лист** — строки, которые встречаться не должны: почта, телефон, имя, домашний путь, имя
    компьютера. Сам список лежит вне репозиториев, в настройках пользователя, и тоже никуда не попадает.
- **У репозитория с удалённой копией — сканер секретов в CI** по каждому push: на случай, если хук обошли.

## Если личное уже попало в историю

1. **Секрет — сразу отозвать и выпустить новый.** Это главный шаг: копии истории уже могли разойтись.
2. Убрать из истории: переписать (замена строк, удаление файлов, замена авторов) или схлопнуть историю в один коммит.
3. Если репозиторий уже был снаружи — переписанную историю отправить с `--force`, старые ветки и теги удалить, о
   форках и кэшах помнить: они остаются.

## Проверка

Репозиторий соответствует, если:

- сканер секретов по **всей истории** (все ветки и теги) чистый;
- ни одна строка из стоп-листа не встречается ни в одной версии файлов и ни в одном сообщении коммита;
- у всех коммитов автор и коммиттер — адрес-заглушка хостинга;
- `private/`, `*.local`, `*.local.*` в `.gitignore` проекта, и ни один такой путь не встречается в истории;
- в истории нет файлов баз, дампов, логов, архивов бэкапов, закрытых ключей;
- в `CLAUDE.md` и подобных нет абсолютных путей.

Машина соответствует, если глобально заданы `user.useConfigOnly=true`, `core.excludesFile` с `private/`, `*.local`,
`*.local.*` и хук с двумя проверками.
