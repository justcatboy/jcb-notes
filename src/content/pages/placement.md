На сайте есть места для баннеров. Здесь — что для этого нужно и какими должны быть файлы: общие требования
и отдельно для каждого места.

## Общие требования

### Что прислать

- **Баннер** — картинка или SVG, требования ниже.
- **Ссылку**, куда он ведёт.
- **Короткое описание** того, что на баннере, — для тех, кто читает сайт с экранным диктором.

### Содержание

- Анимация — можно; подходит ли она, решает сайт.
- Без элементов, которые выдают себя за часть сайта или системы: кнопок «Скачать», окон с предупреждениями,
  фальшивых уведомлений.
- Без звука, всплывающих окон и сбора данных.

### Светлая и тёмная тема

У сайта две темы: светлый фон `#f8f6f1` и тёмный `#1d1b18`. Достаточно одного баннера — лучше со своим
непрозрачным фоном, тогда он хорошо смотрится в обеих.

По желанию можно больше:

- два файла — для светлой и для тёмной темы; сайт сам покажет нужный;
- адаптивный SVG — сам перекрашивается под тему (см. «В стиле сайта»).

### Картинка

- **PNG, JPG или WebP**; с анимацией — GIF, анимированный WebP или APNG.
- Размер в пикселях — вдвое больше размера места, чтобы на чётких экранах не было размытия. Размер места
  указан в его разделе.
- До 200 КБ, с анимацией — до 500 КБ.
- Текст на картинке — крупный: баннер показывается небольшим.

### SVG

- Один файл с атрибутом `viewBox`, без `width` и `height`: ширину задаёт место.
- Без скриптов и ссылок внутри файла: адрес, куда ведёт баннер, задаёт место.
- Анимация — элементами SVG (`<animate>`, `<animateTransform>`).
- Без внешних ресурсов: шрифтов, картинок, стилей по ссылкам. Текст — в кривых: шрифт посетителя может
  отличаться от вашего.
- Растровые вставки (`<image>`) — нет; если нужна картинка, лучше прислать баннер картинкой.
- В начале — `<title>` с текстом баннера.
- До 20 КБ.

### В стиле сайта

Необязательно, но баннер в стиле сайта выглядит его частью.

- **Стиль** — «бумага»: моноширинный текст, тонкие линии толщиной 1–1,5, пунктир (`stroke-dasharray: 3 2.5`),
  один акцентный цвет, без теней и градиентов.
- **Шрифт** — JetBrains Mono, начертания 400 и 700.
- **Цвета:**

| Цвет | Для чего | Светлая тема | Тёмная тема | Переменная |
|---|---|---|---|---|
| основной | текст | `#27241f` | `#e4ded2` | `--fg` |
| приглушённый | второстепенный текст, линии | `#757065` | `#9a9284` | `--muted` |
| акцент | призыв, ссылка | `#2a4a86` | `#a6bde6` | `--accent` |
| линии | тонкие разделители | `#dcd7cc` | `#36322c` | `--line` |
| фон | фон страницы | `#f8f6f1` | `#1d1b18` | `--bg` |

**Адаптивный SVG.** SVG можно сделать таким, что он сам перекрашивается под тему сайта: цвета — переменными из
последней колонки, в атрибуте `style` (`style="fill: var(--fg)"`), фон — прозрачный. Такой SVG встраивается прямо
в страницу, поэтому в нём можно оставить текст шрифтом JetBrains Mono — сайт уже загружает его. Блок `<style>`
внутри такого SVG не подходит: его правила действуют на всю страницу.

## Место: правая колонка главной

Под календарём на главной. Над баннером сайт ставит маленькую подпись «реклама».

| | |
|---|---|
| Пропорция | 2:1 |
| Картинка | 480 × 240 px |
| SVG | `viewBox="0 0 240 120"` |
| Поля | 8 из 240 по каждому краю — ближе к краю ничего важного |
| Ширина на экране | около 190 px на компьютере, до 560 px на телефоне |
| Текст | от 14 из 240 по высоте (в картинке — от 28 px): на компьютере это около 11 px |
| Строк текста | до трёх |

Пример баннера в стиле сайта — второе место на главной.
